# Cover Flow Player — .exe и .apk

В папке `www/index.html` лежит сам плеер. Из него собираются:
- **Windows (.exe)** через Electron;
- **Android (.apk)** через Capacitor.

## Самый простой способ: сборка на GitHub
1. Создайте новый репозиторий на GitHub и загрузите в него всё содержимое этой папки (включая скрытую папку `.github`).
2. Откройте вкладку **Actions**. Сборка запустится сама после загрузки. Если нет, выберите «Build apps» и нажмите **Run workflow**.
3. Через 5–10 минут откройте завершённый запуск и внизу, в разделе **Artifacts**, скачайте:
   - `CoverFlow-Windows-installer`: установщик `.exe`;
   - `CoverFlow-Android-apk`: файл `app-debug.apk`.

## Сборка у себя на компьютере
Нужен Node.js 20.

**Windows .exe:**
```
npm install
npm run dist:win
```
Установщик появится в папке `dist`. Для проверки без установки: `npm start`.

**Android .apk:** нужны Android Studio и JDK 17.
```
npm install
npx cap add android
npx cap sync android
npx cap open android
```
В Android Studio: Build → Build APK(s).

## Что умеет приложение
- Cover Flow, плейлисты (перетаскивание, свои обложки), список треков с поиском и перетаскиванием.
- Избранное: сердечко рядом с названием, автоматический плейлист «Избранное».
- Плейлисты сохраняются между запусками (внутри приложения хранятся копии файлов).
- Обложки и тексты (.lrc) ищутся в интернете, цвет интерфейса берётся из обложки.
- 12 языков интерфейса (настройки → язык): русский, украинский, английский, испанский, немецкий, французский, итальянский, португальский, польский, турецкий, китайский, японский.
- Плеер запоминает не только трек, но и место в нём: после перезапуска продолжает с того же момента.
- Темы: тёмная, светлая, как в системе; цвет акцента можно выбрать вручную (или брать из обложки).
- Скорость, таймер сна, эквалайзер (пресеты), плавные переходы, перемешивание и повтор.
- Windows: медиаклавиши и Ctrl+Shift+T (окно поверх всех окон). Плейлист из папки (кнопка папки в меню плейлистов).

## Важно
- Android: фоновое воспроизведение подключено экспериментально (папка `android-bg`, служба на переднем плане). В шторке уведомлений и на экране блокировки есть кнопки: назад, пауза/играть, вперёд (на Android 13+ приложение попросит разрешение на уведомления). Если сборка с ним не получится, GitHub сам соберёт apk без него и музыка может останавливаться при блокировке экрана.
- Хранение файлов внутри приложения занимает место на устройстве. Удаление плейлиста удаляет и его копии файлов.
- Windows может показать предупреждение SmartScreen: установщик не подписан. Нажмите «Подробнее» → «Выполнить в любом случае».
- Чтобы поставить apk, на телефоне нужно разрешить установку из неизвестных источников. Это debug-сборка, для Google Play нужна отдельная подпись.
- Если меняете плеер, правьте `www/index.html` и снова отправьте изменения на GitHub.
