# Coverly — .exe и .apk

В папке `www/index.html` лежит сам плеер. Из него собираются:
- **Windows (.exe)** через Electron;
- **Android (.apk)** через Capacitor.

## Сайт на Vercel (скачивание, описание, политика конфиденциальности)
В папке `site/` лежит готовый сайт: главная страница с описанием и кнопками скачивания, страница `/privacy.html` (политика конфиденциальности на русском, украинском и английском) и веб-версия плеера по адресу `/app/`.
Кнопки скачивания сами берут **последний релиз** с GitHub: после каждой сборки сборка публикует релиз с файлами `Coverly-Setup-<версия>.exe`, `Coverly-<версия>.apk` и (если собрался) `Coverly-<версия>-legacy.apk` для Android 5.1–6.0.

Как запустить:
1. Откройте `site/config.js` и впишите: `repo` (ваш репозиторий вида `имя/coverly`), `email` (контакт из политики конфиденциальности) и `owner` (ваше имя или название). Позже, когда приложение появится в магазинах, добавьте `playUrl` и `storeUrl`: на сайте покажутся кнопки магазинов.
2. Репозиторий должен быть публичным (иначе сайт не сможет читать релизы).
3. На vercel.com нажмите Add New → Project и выберите репозиторий. Подходят оба варианта: оставить корень репозитория (настройки лежат в `vercel.json`) или указать Root Directory = `site` (тогда работает `site/vercel.json`). В обоих случаях включены «чистые адреса»: страница `privacy.html` открывается и как `/privacy.html`, и как `/privacy`.
   Веб-версия плеера лежит в `site/app/`. При сборке из корня репозитория она обновляется из папки `www` автоматически, при Root Directory = `site` используется уже лежащая там копия: после правок в `www/index.html` скопируйте её и в `site/app/`. После публикации сайт обновляется сам при каждом изменении в репозитории, а ссылки на файлы всегда указывают на последний релиз.
4. Адрес `https://ваш-сайт.vercel.app/privacy.html` указывайте как ссылку на политику конфиденциальности в Google Play и в кабинете Start.io.

Если подключите свой домен, в тексте ничего менять не нужно.

## Какие Android поддерживаются
- **Основная сборка:** Android 7.0 и новее (около 98% устройств), целевой Android 16 (API 36). Именно такая сборка подходит для Google Play: с 31 августа 2026 магазин принимает только приложения для Android 16.
- **Для старых телефонов (Android 5.1 и 6.0):** GitHub отдельно собирает `Coverly-Android-legacy-apk`. Он ставится вручную и в Google Play не загружается, потому что целится в более старый Android. Новый Capacitor 8 поддерживает только Android 7.0+.

## Самый простой способ: сборка на GitHub
1. Создайте новый репозиторий на GitHub и загрузите в него всё содержимое этой папки (включая скрытую папку `.github`).
2. Откройте вкладку **Actions**. Сборка запустится сама после загрузки. Если нет, выберите «Build apps» и нажмите **Run workflow**.
3. Через 5–10 минут откройте завершённый запуск и внизу, в разделе **Artifacts**, скачайте:
   - `Coverly-Windows-installer`: установщик `.exe`;
   - `Coverly-Android-apk`: файл `app-debug.apk`.

## Подписанный релиз для Google Play (.aab)
Google Play принимает только подписанный пакет `.aab`. Для этого нужен свой ключ загрузки (один раз):
1. Установите Java и создайте ключ (запомните пароли и **сохраните файл в надёжном месте**):
   ```
   keytool -genkeypair -v -keystore upload-keystore.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000
   ```
2. Превратите файл в текст:
   - Windows (PowerShell): `[Convert]::ToBase64String([IO.File]::ReadAllBytes("upload-keystore.jks")) | Set-Clipboard`
   - macOS / Linux: `base64 -w0 upload-keystore.jks`
3. На GitHub откройте репозиторий → Settings → Secrets and variables → Actions → New repository secret и добавьте четыре секрета:
   - `ANDROID_KEYSTORE_BASE64`: текст из шага 2;
   - `ANDROID_KEYSTORE_PASSWORD`: пароль хранилища;
   - `ANDROID_KEY_ALIAS`: псевдоним (в примере `upload`);
   - `ANDROID_KEY_PASSWORD`: пароль ключа.
4. Запустите сборку (Actions → Build apps → Run workflow). В артефактах появятся `Coverly-Android-release-aab` (его загружают в Play Console) и `Coverly-Android-release-apk` (подписанный apk для проверки на телефоне).
5. В Play Console включите Play App Signing, как предложит магазин: тогда Google сам хранит основной ключ, а ваш ключ только подтверждает загрузку.

Номер версии (`versionCode`) растёт сам с каждой сборкой, название версии берётся из `package.json` (поле `version`).
Без этих секретов собирается только пробный `apk`.

## Сборка у себя на компьютере
Нужен Node.js 20.

**Windows .exe:**
```
npm install
npm run dist:win
```
Установщик появится в папке `dist`. Для проверки без установки: `npm start`.

**Android .apk:** нужны Android Studio и JDK 17.
```
npm install
npx cap add android
npx cap sync android
npx cap open android
```
В Android Studio: Build → Build APK(s).

## Что умеет приложение
- Cover Flow, плейлисты (перетаскивание, свои обложки), список треков с поиском и перетаскиванием.
- Избранное: сердечко рядом с названием, автоматический плейлист «Избранное».
- Плейлисты сохраняются между запусками (внутри приложения хранятся копии файлов).
- Обложки и тексты (.lrc) ищутся в интернете, цвет интерфейса берётся из обложки.
- 12 языков интерфейса (настройки → язык): русский, украинский, английский, испанский, немецкий, французский, итальянский, португальский, польский, турецкий, китайский, японский.
- Плеер запоминает не только трек, но и место в нём: после перезапуска продолжает с того же момента.
- Темы: тёмная, светлая, как в системе; цвет акцента можно выбрать вручную (или брать из обложки).
- Список треков: долгое нажатие на строку включает выбор нескольких треков. Доступны «играть следом» (очередь), перенос или копирование в другой плейлист и удаление (удаление в два нажатия).
- Резервная копия: Настройки → Резервная копия. «Экспорт с музыкой» сохраняет всё в один zip-файл, «только плейлистов» делает маленький файл; при импорте плейлисты возвращаются, а треки без файлов подхватятся, когда вы снова добавите те же файлы. На Android файл сохраняется в «Загрузки/Coverly».
- Веб-версия (`/app/`) устанавливается как приложение (PWA) и работает без интернета: кнопка «Установить приложение» в настройках или меню браузера.
- Скорость, таймер сна, эквалайзер (пресеты), плавные переходы, перемешивание и повтор.
- Windows: медиаклавиши и Ctrl+Shift+T (окно поверх всех окон). Плейлист из папки (кнопка папки в меню плейлистов).

## Виджет Android
После установки apk: долгое нажатие на пустом месте рабочего стола → «Виджеты» → «Coverly». В виджете обложка, название и кнопки «назад / играть-пауза / вперёд». Нажатие на обложку открывает плеер. Если плеер не запущен, кнопки просто открывают его.

## Реклама Start.io
Внизу экрана **Android-версии** показывается небольшой рекламный баннер сети Start.io. Сейчас в `www/ads-config.js` стоит тестовый App ID Start.io (`205489527`): показываются пробные баннеры, дохода они не приносят. В версии для Windows, в браузере и в старой сборке для Android 5.1–6.0 рекламы нет.

Как включить настоящую рекламу:
1. Зарегистрируйтесь на portal.start.io, добавьте приложение Android с именем пакета `com.coverly.app` и скопируйте его App ID.
2. В `www/ads-config.js` впишите свой `startioAppId` и поставьте `testing: false`.
3. Отправьте изменения на GitHub: сборка сама пропишет идентификатор в приложение.

Правила: не нажимайте на собственную рекламу (аккаунт заблокируют). Start.io просит, чтобы в политике конфиденциальности приложения была ссылка на их политику, она уже есть в политике на сайте. При публикации в Google Play укажите, что в приложении есть реклама и что используется рекламный идентификатор.

## Важно
- Android: фоновое воспроизведение подключено экспериментально (папка `android-bg`, служба на переднем плане). В шторке уведомлений и на экране блокировки есть кнопки: назад, пауза/играть, вперёд (на Android 13+ приложение попросит разрешение на уведомления). Если сборка с ним не получится, GitHub сам соберёт apk без него и музыка может останавливаться при блокировке экрана.
- Хранение файлов внутри приложения занимает место на устройстве. Удаление плейлиста удаляет и его копии файлов.
- Windows может показать предупреждение SmartScreen: установщик не подписан. Нажмите «Подробнее» → «Выполнить в любом случае».
- Чтобы поставить apk, на телефоне нужно разрешить установку из неизвестных источников. Пробный (debug) apk не для магазина: для Google Play используйте подписанный `.aab`.
- Если меняете плеер, правьте `www/index.html` и снова отправьте изменения на GitHub.
